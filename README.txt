HARISH // CYBERPUNK PORTFOLIO

Files:
- index.html  -> Home page
- about.html  -> About page
- style.css   -> Design and responsive layout
- script.js   -> Mobile navigation

PHONE WORKFLOW:
1. Upload these files to a GitHub repository.
2. Open Cloudflare Dashboard.
3. Workers & Pages -> Create application -> Pages -> Connect to Git.
4. Select the GitHub repository.
5. Framework preset: None.
6. Build command: exit 0
7. Build output directory: .
8. Deploy.

Before publishing:
- Replace your@email.com in about.html.
- Replace the GitHub URL.
- Add your own projects.
- Optionally add assets/profile.jpg.

The design uses Google Fonts from fonts.googleapis.com. If you want zero external requests,
replace the fonts with system fonts in style.css.
